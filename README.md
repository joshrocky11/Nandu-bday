# Happy Birthday, Nandhu ✨

A guided birthday surprise inspired by the attached example: a dark, glowing backdrop, floating hearts, frosted-glass cards, an envelope and typewritten note, one personal photo, flip-to-reveal wishes, and a 20-second star-catching game.

## Run it

1. Keep the `nandhu-birthday` folder together.
2. Open `index.html` in a current browser.
3. Follow the prompts from the welcome card through the birthday surprise.
4. The supplied photo appears in the memory garden. Choose **＋ Replace this photo** any time to pick a different one.

The supplied photo is bundled with the project. Any replacement is resized and saved in that browser on that device; it is not uploaded to a server. The page uses no install step or external libraries.

The audio-only background score is included as `birthday-score.mp3`; it does not need an internet connection. Tap **Birthday soundtrack** to play or pause it. Browsers require a user tap before a site can start audio.

## Publish it

Upload the complete `nandhu-birthday` folder to a static web host such as GitHub Pages, Netlify, or Cloudflare Pages. Keep `index.html`, `styles.css`, and `app.js` together. No build command or backend is needed.

The bundled photo appears for everyone on a published site. A photo chosen with the replacement control is private to that visitor's browser.

## Personalize the wishes

Edit the birthday message in `app.js`. Edit the visible headings and flip-card wishes in `index.html`. Colors, layout, and animations are in `styles.css`.
